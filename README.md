# GitHub Uploader

Android-приложение для загрузки файлов на GitHub. Получает **две рабочие ссылки** на один файл:

- 📥 **Прямая ссылка для скачивания** — файл кладётся в GitHub Release, ссылка скачивает его.
- 👀 **Ссылка для просмотра в браузере** — файл записывается в репозиторий, и по ссылке фото/видео открываются прямо в браузере, без скачивания.

## Возможности

- **Два режима подключения GitHub в Настройках** с мгновенным переключением:
  - **Через GitHub (OAuth Web Flow без кода + авто-возврат `gitstorage://callback`)** — нажатие кнопки открывает страницу согласия GitHub в браузере без ручного ввода кода, а после нажатия **Authorize** браузер автоматически возвращает пользователя обратно в приложение, подгружает все его репозитории и позволяет в 1 касание переключать, создавать и удалять их. *(Перед сборкой APK в Sketchware Pro вставьте ваш `Client Secret` в константу `CLIENT_SECRET` в начале `GitHubAccountManager.java`).*
  - **Ручной режим** — достаточно ввести только Personal Access Token и нажать «Показать репозитории токена» (либо заполнить поля владельца, репозитория и веток вручную, как раньше).
- **Гибкое управление ветками (`▾`, по умолчанию `main`) и выбор папки на ветке**: по умолчанию после авторизации сразу выбирается ветка **`main`**, при желании можно переключать ветку загрузки, создавать новые ветки, удалять дополнительные ветки или вводить имя вручную; а на главном экране под полем **«Тег релиза»** расположено поле **«Папка на ветке»** — последние введённые тег релиза и название папки автоматически сохраняются при каждом изменении.
- **Умные предупреждения о лимитах размера файла**: автоматическая проверка порогов перед загрузкой (**до 20 МБ** для быстрого CDN jsDelivr, **до 65 МБ** для ветки просмотра с переключением на `raw`, и **до 2 ГБ** для прямого скачивания через GitHub Releases без лишних предупреждений).
- Material 3 дизайн, градиентные карточки, векторные иконки, поддержка светлой и тёмной темы, корректная адаптивная иконка приложения.
- Запрос полного разрешения на доступ к файлам при запуске (`MANAGE_EXTERNAL_STORAGE` на Android 11+ / `WRITE_EXTERNAL_STORAGE` на Android 6–10).
- **Диалог выбора формата** при нажатии «Выбрать файл»: **Фотография** (автоматически подставляет `photo` в тег релиза и папку на ветке), **Видео** (`video`) или **Файл** (`files`).
- **Диалог выбора цели перед загрузкой**: скачивание, просмотр в браузере или оба варианта сразу.
- **Онлайн-история через GitHub API**: после ввода данных репозитория и токена в настройках приложение автоматически загружает в историю все файлы, которые уже есть в GitHub Releases и в ветке предпросмотра (`files/`), даже после переустановки приложения или на новом устройстве.
- **Удаление любых файлов и раздельное удаление ссылок**: если у файла загружены оба варианта («Скачивание + Просмотр»), можно удалить **только ссылку на скачивание** (из Releases), **только ссылку на просмотр** (из ветки `files`) или **оба варианта сразу** — через умный диалог выбора при нажатии «Удалить» либо через быстрые значки корзин рядом с каждой ссылкой.
- Собственный предпросмотр фото и видео внутри приложения.
- Настройки репозитория (owner, repo, токен, ветки) с проверкой соединения.
- Прогресс-бар при загрузке.

## Почему для просмотра нужно хранить файл в репозитории

GitHub Releases всегда отдают файл с заголовком:

```
Content-Disposition: attachment
```

Из-за этого браузер **скачивает** файл, а не показывает его.

Поэтому для ссылки «просмотр в браузере» приложение записывает файл в сам репозиторий (на отдельную ветку, по умолчанию `files`). Оттуда работают прямые ссылки с правильным `Content-Type`:

- CDN **jsDelivr** (приоритетная ссылка в приложении):
  `https://cdn.jsdelivr.net/gh/<owner>/<repo>@files/files/<файл>`
- **raw** GitHub:
  `https://raw.githubusercontent.com/<owner>/<repo>/files/files/<файл>`

## Как получить токен

1. Войдите в GitHub → **Settings → Developer settings → Personal access tokens**.
2. Создайте токен с правом **`repo`** (для публичных репозиториев можно `public_repo`).
3. Введите owner, repo, токен и ветки в приложении → **Настройки** → **Сохранить** / **Проверить соединение**.

Токен хранится только на устройстве (в SharedPreferences).

## Структура

```
app/src/main/java/com/bayram/githubfileupload/
  MainActivity.java             — главный экран, разрешения, выбор формата/файла, загрузка
  FileFormatDialogFragment.java — диалог выбора формата: Фотография / Видео / Файл
  UploadChoiceBottomSheet.java  — диалог выбора цели загрузки
  ConfigActivity.java                 — два режима настроек: вход через GitHub и ручной токен
  GitHubAccountManager.java           — OAuth Device Flow, список, создание и удаление репозиториев
  GitHubDeviceAuthDialogFragment.java — диалог входа через GitHub по одноразовому коду
  CreateRepoDialogFragment.java       — создание нового публичного репозитория с README.md
  DeleteRepoDialogFragment.java       — подтверждение полного удаления репозитория и всех файлов
  RepoListAdapter.java                — адаптер списка репозиториев аккаунта
  BranchPickerDialogFragment.java     — выбор, создание, удаление и ручной ввод ветки
  BranchListAdapter.java              — адаптер списка веток репозитория
  FileSizeWarningDialogFragment.java  — умные предупреждения о лимитах размера (20 МБ / 65 МБ / 2 ГБ)
  HistoryActivity.java          — онлайн-история загрузок с полным и раздельным удалением
  DeleteChoiceDialogFragment.java — диалог выбора: удалить скачивание / просмотр / оба варианта
  HistoryAdapter.java           — адаптер карточек истории
  GitHubHistoryManager.java     — синхронизация истории и удаление через GitHub API
  PreviewActivity.java          — предпросмотр фото/видео по ссылке
  GitHubReleaseManager.java     — загрузка и точечное удаление файлов в Releases
  GitHubRepoManager.java        — запись и удаление файлов в ветке репозитория
  UploadService.java            — оркестратор загрузки
  FileUtils/ImageLoader/Prefs   — вспомогательные классы
```
