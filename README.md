# GitHub Uploader

Android-приложение для загрузки файлов на GitHub. Получает **две рабочие ссылки** на один файл:

- 📥 **Прямая ссылка для скачивания** — файл кладётся в GitHub Release, ссылка скачивает его (как и в прежней версии).
- 👀 **Ссылка для просмотра в браузере** — файл записывается в репозиторий, и по ссылке фото/видео открываются прямо в браузере, без скачивания.

## Возможности

- Полностью переработанный дизайн: Material 3, градиентный дизайн, векторные иконки, тёмная тема.
- Выбор файла через систему (SAF) — любые фото, видео, документы.
- **Диалог перед загрузкой**: загружаете для скачивания, для просмотра в браузере или для обоих вариантов сразу.
- Две ссылки в результате: копирование, открытие и отправка поделиться.
- История загрузок с превьюшками.
- Собственный предпросмотр фото и видео внутри приложения.
- Настройки репозитория (owner, repo, токен, ветки) с проверкой соединения.
- Прогресс-бар при загрузке.

## Почему для просмотра нужно хранить файл в репозитории

GitHub Releases всегда отдают файл с заголовком:

```
Content-Disposition: attachment
```

Из-за этого браузер **скачивает** файл, а не показывает его — заголовок нельзя изменить с стороны GitHub.

Поэтому для ссылки «просмотр в браузере» приложение дополнительно записывает файл в сам репозиторий (на отдельный ветвь, по умолчанию `files`). Оттуда уже работают прямые ссылки, которые отдают файл с правильным `Content-Type` и без принудительного скачивания:

- CDN **jsDelivr** (приоритетная ссылка в приложении):
  `https://cdn.jsdelivr.net/gh/<owner>/<repo>@files/files/<файл>`
- **raw** GitHub:
  `https://raw.githubusercontent.com/<owner>/<repo>/files/files/<файл>`

Открыв такую ссылку в браузере, друзья сразу увидят фото или видео.

## Как получить токен

1. Войдите в GitHub → **Settings → Developer settings → Personal access tokens**.
2. Создайте токен с правом **`repo`** (для публичных репозиториев можно `public_repo`).
3. Введите owner, repo, токен и ветки в приложении → **Настройки** → **Проверить соединение**.

Токен хранится только на устройстве (в SharedPreferences).

## Запуск

Откройте проект в **Android Studio** (Hedgehog+) или скомпилируйте:

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

- minSdk 21, targetSdk 34, AGP 8.12, Gradle 8.13.

## Про приватные репозитории

Прямая ссылка на просмотр работает только для **публичных** репозиториев (raw и jsDelivr недоступны для приватных без авторизации). Для приватного репозитория приложение покажет соответствующее сообщение — скачивание через релиз при этом продолжает работать.

## Структура

```
app/src/main/java/com/bayram/githubfileupload/
  MainActivity.java            — главный экран, выбор файла, диалог, результат
  ConfigActivity.java          — настройки GitHub
  HistoryActivity.java         — история загрузок
  PreviewActivity.java         — предпросмотр фото/видео по ссылке
  HistoryAdapter.java
  UploadChoiceBottomSheet.java — диалог выбора цели загрузки
  GitHubReleaseManager.java    — загрузка в Release → ссылка для скачивания
  GitHubRepoManager.java       — запись в репозиторий → ссылки для просмотра
  UploadService.java           — orchestrator
  FileUtils/ImageLoader/...    — вспомогательные классы
```
